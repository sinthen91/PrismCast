# Current PrismCast Development Baseline

**Current development version:** `0.2.0-alpha.61`

Canonical project: `PrismCast/PrismCast.csproj`

Alpha.61 adds persistent Screen Share quality presets for 720p30, 1080p30, and 1080p60, including matching dynamic in-world render textures for host and viewers. It also adds per-device embedded-subtitle control and removes the redundant bottom player from the Session page in both Mobile and Tablet layouts, freeing the full area for Groups. Alpha.60's reliable `/prism` and `/prismcast` commands remain intact.

GitHub `main` is the source of truth after this baseline is committed.
